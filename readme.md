# Haoyang Xian - Academic Portfolio

This is a static, lightweight academic website built with semantic HTML and plain CSS, themed around classical print typography and colors.

## File Structure
- `index.html`: Main page structure.
- `assets/css/style.css`: Decoupled stylesheet preserving the #FDFBF7 (cream) and #8B1A1A (dark red) palette.
- `assets/js/main.js`: Basic interactivity script.
- `assets/docs/CV_Haoyang_Xian.pdf`: Directory for the downloadable PDF CV.

## Deployment via GitHub Pages
1. Create a repository on GitHub named `HaoyangXian.github.io`.
2. Initialize and push your code:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of academic website"
   git branch -M main
   git remote add origin [https://github.com/HaoyangXian/HaoyangXian.github.io.git](https://github.com/HaoyangXian/HaoyangXian.github.io.git)
   git push -u origin main
